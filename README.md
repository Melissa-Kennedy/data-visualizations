# Data Visualizations

A collection of data-visualization projects — sketches, prototypes, and
finished builds.

## Projects

### [Crosswordese](./crosswordese)

**Live: [crosswordese.lovable.app](https://crosswordese.lovable.app)**

The 100 most-used answer words in the New York Times crossword (Will Shortz
era, 1993–2026), interlocked into one real, correctly-numbered crossword
grid and shaded by frequency, with real historical clues alongside it.
Includes the original static prototype and the full data pipeline (word
frequency source, crossword-packing/numbering algorithm, real-clue
extraction) — see [`crosswordese/README.md`](./crosswordese/README.md).

### [Punctuation Pals](./punctuation)

**Lovable project: [lovable.dev/projects/bc399feb-7844-4b5b-af07-d893e0682c12](https://lovable.dev/projects/bc399feb-7844-4b5b-af07-d893e0682c12)**

A kid-friendly punctuation explorer for a grade 4 reader. Type a mark like
`?` or `!` to see what it does, how it feels in emojis, how it sounds read
aloud, and an example sentence on handwriting paper. Includes the original
single-file prototype — see [`punctuation/README.md`](./punctuation/README.md).
